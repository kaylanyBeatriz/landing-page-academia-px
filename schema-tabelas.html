Schema do Banco de Dados — Kit NR 35

Tabelas: usuarios, materiais, usuario_materiais

1. usuarios

ColunaTipoRegras
idUUIDPK, gerado automaticamente
nome_completoTEXTobrigatório
cargoTEXTobrigatório
emailTEXTobrigatório
telefoneTEXTobrigatório
empresaTEXTobrigatório
consentimento_lgpdBOOLEANobrigatório, default false
token_acessoTEXTtoken/JWT emitido para manter "desbloqueado"
created_atTIMESTAMPdefault agora

2. materiais

ColunaTipoRegras
idUUIDPK, gerado automaticamente
nomeTEXTobrigatório
tituloTEXT—
descricaoTEXT—
tipoTEXT"PDF/DOCX", "PPTX", "Canva" etc
iconeTEXT"clipboard", "presentation", "book", "palette"
link_downloadTEXTobrigatório
arquivo_keyTEXTcaminho/key no storage (S3 etc), não a URL pública
ordemINTEGERopcional, ordenação na grid
ativoBOOLEANopcional, permite esconder sem apagar
contador_clicksINTEGERdefault 0, incrementado a cada download
created_atTIMESTAMPdefault agora

3. usuario_materiais (tabela de vínculo)

ColunaTipoRegras
idUUIDPK, gerado automaticamente
usuario_idUUIDFK → usuarios.id, obrigatório
material_idUUIDFK → materiais.id, obrigatório
downloaded_atTIMESTAMPdefault agora (quando ocorreu o download)
