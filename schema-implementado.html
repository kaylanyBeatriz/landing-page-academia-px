2. O que a landing page NÃO consegue fazer (por desenho)

A chave pública (anon) usada no front não tem permissão de leitura/escrita em nenhuma tabela acima — só executa as 4 funções da seção 3. Isso é o que garante que o link do arquivo não vaza antes do cadastro (gated content).

3. Funções (RPC) consumidas pela LP — script.js

3.1 lp_list_materials carregamento da página

POST /rest/v1/rpc/lp_list_materials
{ "p_lp_slug": "kit-nr-35" }

Retorna a lista de materiais ativos da LP (sem links de download) para montar a grid. Chamada em loadMaterials().

3.2 lp_validate_token carregamento da página

POST /rest/v1/rpc/lp_validate_token
{ "p_token": "<token salvo no localStorage>" }

Se houver token salvo (academia_kit_nr35_token), valida a sessão e libera o acesso automaticamente, sem pedir o formulário de novo. Token inválido/expirado é removido.

3.3 lp_register_lead envio do formulário

POST /rest/v1/rpc/lp_register_lead
{
  "p": {
    "lp_slug": "kit-nr-35",
    "full_name": "…", "job_title": "…", "email": "…",
    "phone": "…", "company": "…",
    "consent_given": true, "consent_version": "v1",
    "utm_source": "…", "utm_medium": "…", "utm_campaign": "…",
    "utm_content": "…", "utm_term": "…", "gclid": "…", "fbclid": "…",
    "referrer": "…", "landing_page": "…"
  }
}

Resposta: { "access_token": "…", "expires_at": "…" } — salvo em localStorage e usado para liberar a grid. Reenviar o mesmo e-mail atualiza o lead existente em vez de duplicar.

3.4 lp_register_download clique no card

POST /rest/v1/rpc/lp_register_download
{ "p_token": "…", "p_material_id": "…uuid…" }

Chamada só no clique (nunca no carregamento) — o link expira em 5 minutos. Resposta: { "download_url": "…", "expires_in": 300, "name": "…" }. Token inválido (erro 28000) limpa a sessão e reexibe o formulário.
